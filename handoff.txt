RELEASE GATE / KNOWN LIMITS
Real Appwrite parent login/logout, two existing child profiles, cross-device
refresh/sync, existing historical mastery and purchases still require an
owner-controlled authenticated session. No live child data was inspected or
modified. Recheck OCR/photo approval and parent definition editing manually.
Cloud database and collection permissions were not modified or independently
proven by these demo tests. Supabase was not exercised.
The inherited coin update + progress save is not a cross-document server
transaction. Same-page duplicate actions are guarded and tested; simultaneous
tabs/devices or a network failure between those writes remain a backend risk.
Do not claim this is server-atomic; address with a trusted transactional
purchase endpoint before promising cross-device purchase guarantees.
The existing >500 kB bundle warning remains (main bundle ~722 kB uncompressed).
Fonts were blocked during browser QA; installed fallback fonts are shown.
Physical touch-device audio and camera permission flows need manual review.
Sprints 2/3 additions (new modalities, region map, parental gate, cosmetics)
are outside this stage. Existing functionality is preserved.
Owner visual and cloud-data review precedes release; do not extrapolate art
to the other territories before that review. Production remains unchanged by
this upgrade at https://www.kingdomspellers.com/.
