## Installation
1. BACK UP or commit your existing project before making changes.
2. Extract this ZIP INTO THE ROOT of your existing `kingdom-spellers` repository, preserving directories.
3. Open `agent/PASTE_TO_VSCODE_AGENT.md` and paste the entire text into your VS Code coding agent.
4. The agent must inspect and integrate existing components. Nothing in this pack should automatically replace `src/`, database tables, or existing deployment configuration.
5. Preview changes locally, validate parent/child data, then deploy.
