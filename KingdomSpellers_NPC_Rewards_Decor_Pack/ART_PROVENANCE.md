# Production art provenance

Built-in image_gen was used, without an API key or new service. The supplied expansion board, six NPC crops, decor/reward references and prior avatar board guided the style. Raw concept crops remain unchanged and are not used as playable sprites. Final files are `public/assets/storybook/{id}.webp` and matching `.png`; original generated sources and sizes are listed in PRODUCTION_ASSETS.json. All character/object images have verified alpha; the academy is an opaque environment. Alpha-bound cropping, resizing and compression prepare the production files; no labels or UI are baked into sprites. Original outputs remain in the Codex generated_images directory. Total WebP transfer size: 664186 bytes across all ten assets, excluding PNG fallbacks.
